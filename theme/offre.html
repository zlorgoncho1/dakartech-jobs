Le poste

Baamtu, entreprise de services numériques spécialisée en data et intelligence artificielle, renforce son pôle Web. Vous rejoignez une équipe de huit développeurs à Dakar (Sacré-Cœur) pour concevoir et faire évoluer les plateformes que nous construisons pour nos clients des secteurs bancaire, télécom et public.

Vous interviendrez sur tout le cycle de vie des applications : modélisation des données, développement des API, revue de code et mise en production. Le poste est proposé en hybride (trois jours sur site par semaine) et rattaché au responsable du pôle Web.

Vos missions

  • Concevoir et développer de nouvelles fonctionnalités avec Django et Django REST Framework.
  • Modéliser les données et optimiser les requêtes PostgreSQL.
  • Écrire des tests automatisés et participer aux revues de code.
  • Conteneuriser et déployer les applications avec Docker et GitLab CI.
  • Accompagner les développeurs juniors et documenter les choix techniques.

Profil recherché

  • 2 à 4 ans d'expérience en développement back-end avec Python et Django.
  • Bonne maîtrise de PostgreSQL, de Git et des principes des API REST.
  • Sensibilité à la qualité du code : tests, lisibilité, revue entre pairs.
  • Autonomie, esprit d'équipe et goût pour la transmission.
  • Bac+3 minimum en informatique (ESMT, ESP, UCAD, ISEP…) ou expérience équivalente.

Avantages

  • Assurance maladie prise en charge à 100 % pour vous et votre famille.
  • Prime de performance annuelle et treizième mois.
  • Budget formation et certifications (Python Institute, AWS).
  • Matériel fourni et télétravail deux jours par semaine.

Compétences

Python Django PostgreSQL Docker Git API REST Tests
